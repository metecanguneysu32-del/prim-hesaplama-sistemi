# Prim Hesaplama Sistemi

## Proje Amacı

Bu proje, mağazaların haftalık hedeflerini takip etmek ve personel primlerini otomatik hesaplamak amacıyla geliştirilmektedir.

## Özellikler

- Kullanıcı Girişi
- Mağaza Yönetimi
- Personel Yönetimi
- Haftalık Hedef Girişi
- Satış Girişi
- Genel Merkez Satışları
- İnternet Satışları
- Prim Hesaplama
- Raporlama
- Excel Aktarma

## Teknolojiler

- Python
- HTML
- CSS
- JavaScript
- SQLite
